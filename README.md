# CodeAlpha Task 2 - Matrix Operations

## About the Project

This project is developed as part of the CodeAlpha C Programming Internship.

The program performs:
- Matrix Addition
- Matrix Multiplication
- Matrix Transpose

## Technologies Used

- C Programming
- Functions
- Two-Dimensional Arrays

## How to Run

Compile:

gcc matrix.c -o matrix

Run:

./matrix

## Sample Output

Matrix Addition:

10 12

Matrix Multiplication:
19 22
43 50

Transpose of Matrix A:
